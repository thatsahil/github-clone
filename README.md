# CodeTrack — LeetCode-inspired UI demo

An independent, responsive frontend prototype for experimenting with profile, activity-calendar, and problem-list UI patterns. Not affiliated with LeetCode and not connected to any LeetCode account.

## Features
- Responsive dark interface
- Interactive monthly calendar cells that toggle local sample interactions
- Problem catalogue with difficulty filtering
- Navigation to official LeetCode pages
- Clearly labelled demo content; no fake historical submissions

## Deploy on Render
Create a Static Site connected to this repository. Leave the build command empty and set the publish directory to `.` (repository root). The entry point is `index.html`.
